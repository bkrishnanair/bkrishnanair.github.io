CHALLENGE

Connect AI capability to working software.

The challenge was not just getting a model to generate questions. The pipeline had to fit into a full-stack learning application, with a database, a user interface, repeatable builds, and tests across the backend and frontend.

How it fits together

Engineering decisions

01

Integrate the model into a complete workflow.

CHALLENGE

Manually translating lecture PDFs into quizzes is repetitive work for educators.

APPROACH

Built a Python pipeline using Llama3 through the Groq API, integrated with Django and React.

RESULT

Automated the conversion from uploaded lecture material to quizzes.

02

Test across the application boundary.

CHALLENGE

A working generation demo does not establish confidence in the surrounding application.

APPROACH

Used test-driven development with unit and integration tests across Django services and React components.

RESULT

Enforced 90% test coverage across the application.

03

Make delivery reproducible.

CHALLENGE

The application combines frontend, backend, database, and external model dependencies.

APPROACH

Containerized the application with Docker and shipped through CI/CD.

RESULT

A repeatable path from development to delivery.

The results

Delivered an end-to-end learning application with automated PDF-to-quiz generation, Docker packaging, CI/CD, and 90% test coverage.

WHAT I TAKE FORWARD

Code coverage measures the application, not the quality of generated questions. A next step would be a curated evaluation set for factual accuracy and question quality, alongside explicit inference-failure tests.
